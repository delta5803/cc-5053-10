# 手工采样键盘 · Hand-built sampling keyboard

一个真正可演奏的采样键盘引擎：用 12 段**自制录音**（6 个八度根音 × 2 个力度层）构建键区与力度层，
按输入音符确定性地选样、重采样、循环延续，并控制起音、持续与释放。

界面入口：**`npm start` 后打开 <http://127.0.0.1:4173/web/index.html>**
（命令只是辅助；所有演奏与检查都在图形界面里完成。）

## 运行说明

1. `npm install`（仅安装 Playwright 用于浏览器自检；运行界面本身无依赖）
2. `npm start`
3. 浏览器打开 <http://127.0.0.1:4173/web/index.html>
4. 点击 **启动引擎**，然后点击琴键或用电脑键盘 `A W S E D F T G Y H U J K` 演奏

界面内可直接：调整力度（1–127）、连奏重叠（0–250 ms）、声部上限（1–32），
用**延音踏板**按钮（或按住 `Shift`）踩下踏板，
触发 **运行循环检查**（接缝与稳态）与 **加载离线报告**（音高、选样、声部、踏板重触发、缓存核对结论）。
键盘下方会显示**按下实例 · 力度层 · 实际读头**对应表：每次按键是一个独立实例，标出它选中的样本、
所属声部与正在读样本的读头编号，以及当前是「按住 / 踏板持有 / 释放中」。

## 引擎规则（可在界面“键区与力度规则”中查看）

- **键区**：根音 C2/C3/C4/C5/C6/C7，键区边界取相邻根音的**向上取整中点**，边界音归**低**根音键区。
  例：C3 键区 MIDI 42..53，C4 键区 54..65；MIDI 54 属于 C4 并使用 C4 录音下移 6 个半音（×0.7071）。
- **力度层**：1–75 柔和层、76–99 交叉淡化（两层同时发声，线性交叉）、100–127 明亮层。
  同一 (音符, 力度) 永远得到同一录音组合与同一重采样比；不会随机换到不相关样本。
- **音高**：播放速率 = 2^(音高差/12)，由同一录音平移；离线报告逐音核对输出音高（≤12 音分）。
- **循环**：每段录音带循环区间与交叉过渡；离线与界面的循环检查会核对接缝跳变（相对局部步长）
  与循环体内 RMS 漂移，并对 4.5 秒长音扫描孤立跳变，避免长音反复“咔哒”。
- **声部**：逻辑声部严格不超过上限；超出时优先偷取最早的释放中声部，其次踏板持有（已松键）的声部，否则偷取最早按住的声部。
  被偷声部以 8 ms 淡出并继续 pin 住缓存，直到尾音结束才允许卸载。每个声部是一个**按键实例**（id），
  不按音高合并：同一音高先轻后重的重触发是两个实例，旧实例的松键只结束它自己。
- **延音踏板**：踏板是“所有权”的集合，只接管**已经松开**的按键实例。踩下踏板后松键不会结束声音，
  而是转为踏板持有；松开踏板时释放所有踏板持有的实例，但仍按住的键不受影响，继续到它自己的松键。
  延音踏板能在同一音高上让轻奏的释放尾音与重击的新起音同时存在，二者各自拥有独立的读头与缓存 pin。
  松开踏板与旧样本读取回调晚到时，释放跟随实例、而不是音高，因此不会终止更新的声部，也不会让尾音永久占住声部。
- **缓存**：有界（默认 2 MB），LRU 驱逐**未被声部使用**的条目；正在发声的样本永不卸载；
  预算不足以装入当前需求时抛出 `CACHE_PINNED_FULL`，界面错误区显示代码、原因与建议。
  每个读头归还缓存（unpin）的时刻与真实叠音轨迹对齐，绝不提前释放另一个声部仍在读取的录音。

## 测试与离线对照

- `npm test`：引擎单元/集成测试（选样、边界音、极低力度、快速同音、音高、循环、缓存、偷声部）
  与浏览器交互测试（真实启动、触发时刻、键盘渲染、循环检查、离线报告加载、错误提示）。
  浏览器测试需要可用的 Chromium；本容器缺少系统库时先设置
  `LD_LIBRARY_PATH`（`.browser-libs/usr/lib/<arch>:...`），或用 `SKIP_BROWSER=1 npm test` 只跑引擎测试。
- `npm run offline`：生成 `docs/offline/report.json`、`summary.txt` 与试听 WAV（含边界音对、力度梯、
  快速重复、长音循环）。

## 目录

- `assets/samples/` — 12 段自制录音（WAV）与 `recordings.json`
- `src/engine.js` — 选样、键区/力度规则、缓存、声部、循环分析、离线渲染（界面与离线共用）
- `src/live.js` — 浏览器实时演奏（Web Audio 图，每声部 BufferSource + 增益包络）
- `src/wav.js` — WAV 解码/编码
- `web/` — 演奏控制面板
- `tools/generate-samples.mjs` — 确定性生成自制录音
- `tools/offline.mjs` — 离线对照
- `tools/serve.mjs` — 静态服务器
- `test/` — 自动化测试
